## Overview

iPhone Duo Software & Tools is a community-oriented collection of software resources for Apple's foldable iPhone Duo.

The project focuses on getting the most out of the device's two displays, iOS 27 features, multitasking capabilities, app compatibility, system maintenance, and developer tools.

The repository is intended for users, developers, and enthusiasts who want to configure, maintain, and explore the iPhone Duo software ecosystem.

This is an independent software collection, not an official Apple product or firmware distribution.

## Firmware Features

iPhone Duo uses Apple's iOS platform rather than a separately installed third-party firmware.

Relevant software capabilities include:

- Foldable display interface adaptation
- External and internal display layouts
- Split View multitasking
- App continuity between display states
- Apple Pencil support
- StandBy enhancements
- Apple Intelligence features
- Camera and video-call enhancements
- System security and recovery updates

**Firmware terminology:**

- **iOS:** Apple's operating system for iPhone.
- **IPSW:** Apple's restore firmware package.
- **OTA update:** Software update delivered directly through iOS.
- **Recovery mode:** Apple's device recovery environment.
- **DFU mode:** Low-level device firmware recovery mode.

A third-party utility or app is not automatically a custom firmware or jailbreak.

### Install applications

1. Open the App Store.
2. Find the application you need.
3. Check its compatibility and permissions.
4. Install the application.
5. Open it and complete the initial configuration.

### Restore firmware

For a manual restore, use an official Apple firmware package compatible with the exact iPhone Duo model.

Supported restore workflows include:

- Finder on macOS
- Apple Devices on supported Windows systems
- Apple-supported recovery procedures

An IPSW file must be compatible with the device and currently signed by Apple for normal restore installation. Restoring can erase device data.

## FAQ

### 1. What is this project?

A community toolkit containing iPhone Duo software resources, setup guides, utilities, and development information.

### 2. Is this an official Apple project?

No. It is an independent community project and is not affiliated with Apple.

### 3. Which iOS version does iPhone Duo use?

The device launched with iOS 27.1. iOS 27.2.1 is the current documented release in this repository.

### 4. Does iPhone Duo support multitasking?

Yes. iOS 27 includes Duo-specific multitasking capabilities, including Split View for compatible applications.

### 5. Does iPhone Duo support Apple Pencil?

Apple Pencil support was introduced for iPhone Duo with iOS 27.2. Check the supported Pencil model and software requirements before pairing.

### 6. Can standard iPhone applications run on iPhone Duo?

Compatible iOS applications can run on the device. However, applications may need updates to take full advantage of its foldable display.

### 7. Can I install applications outside the App Store?

Alternative app distribution depends on Apple's supported installation methods, developer signing, and regional rules. Use trusted sources and verify application signatures.

### 8. Is a jailbreak required to customize iPhone Duo?

No. Many display, accessibility, widget, and application settings can be configured using standard iOS features.

### 9. Can I downgrade iOS?

Only when Apple signs a compatible firmware version for the device. Previously signed versions may no longer be restorable.

### 10. How should I prepare for a firmware restore?

Create a backup, verify the exact device model, check IPSW compatibility and signing status, and use an Apple-supported restore tool.

### 11. Does this repository provide custom firmware?

No. It provides software resources and documentation. It does not claim to offer an independently developed iOS firmware.

### 12. Is the toolkit compatible with other iPhone models?

General iOS resources may be useful on other devices, but Duo-specific display and multitasking instructions are intended for iPhone Duo.
